Network Engineering

A two-site Cisco network connecting a retail location to headquarters over WAN, with RIP routing and DHCP-served client networks.

Objective

Design and configure a network setup connecting a retail site (RRS) to a headquarters site (HQS) using Cisco hardware.

Scope

  • Implemented network infrastructure across two locations
  • Configured two routers at both locations connected via a WAN link
  • Set up two networks at the retail site: a server network and a client network

Key tasks

  • Configured two Cisco K9 2911 routers with HWIC-2T add-ons for WAN connectivity
  • Established Routing Information Protocol (RIP) between both sites for dynamic routing
  • Deployed DHCP on client networks for automated IP address allocation
  • Connected client devices and servers to medium-sized switches supporting 7–20 client devices and 4–7 server ports
  • Tested by connecting PCs at HQS and RRS, verifying communication with successful pings across both networks

Hardware and technologies

  • Cisco K9 2911 routers with HWIC-2T add-ons
  • Cisco 2960-8TC-L and 2960-24TT-L switches
  • Windows PCs for network testing
  • RIP for dynamic routing, DHCP for client network configuration
