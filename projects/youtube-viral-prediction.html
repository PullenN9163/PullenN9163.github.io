YouTube Viral Video Prediction

  1. Home
  2. Projects
  3. YouTube Viral Video Prediction
Machine Learning

Classification models predicting how long a video stays trending, reaching over 97% accuracy across Decision Tree, Random Forest, and KNN.

This project set out to predict whether a YouTube video would trend for a given number of days, using engineered features from a large trending-video dataset.

What I did

  • Engineered features and cleaned large datasets by handling missing values, encoding categorical data, and optimizing variables for machine learning tasks.
  • Developed and evaluated classification models including Decision Trees, Random Forests, and K-Nearest Neighbors (KNN) to predict whether a video would trend for a set number of days.
  • Achieved model accuracy of over 97% and assessed performance using precision, recall, and F1 score to determine the most effective algorithm.

The full project description, analysis, models, visualizations, and results are available in the Colab notebook and the project repository.
