Security Data Analysis

A centralized database and Tableau story that turns raw Shodan ICS scan data into a usable risk assessment for ethical hackers.

Objective

Current ethical hacking practices for gathering and analyzing Industrial Control System data are hard to comprehend and time-consuming. Having one centralized place to analyze and visualize this data would help ethical hackers assess which organizations’ ICS systems are most at risk, and the best way to approach them.

Scope

  • Create a new and efficient ethical hacking practice for interpreting raw Shodan data
  • Develop a centralized database to house Shodan data
  • Create a way to visualize Shodan data for specific ICS types

Key tasks

  • Downloaded Shodan data for all ICS ports (47808, 502, 102, 44818)
  • Reduced the data in Excel to only the relevant fields (IP, location, object name, and similar)
  • Imported the cleaned data into a SQL database
  • Developed queries to pull the data ethical hackers would need
  • Visualized query results in Tableau
  • Analyzed the results to conduct a risk assessment, then published a Tableau story

Representative queries

DescriptionQuery
Show all Shodan entries of products from Obvious
SELECT Model_name, Vendor_name
FROM ShodanResults
WHERE Vendor_name = 'Obvious';
Number of entries per organization for BACnet systems
SELECT COUNT(*) AS Number_of_Entries, ORG, Address_ll
FROM ShodanResults
GROUP BY ORG, Address_ll;
Number of entries per organization for Modbus systems
SELECT COUNT(*) AS Number_of_Entries, ORG, City, State, Country
FROM ShodanResults
WHERE Port = 502
GROUP BY ORG, City, State, Country, Port;
Total entries per ICS type across all ports
SELECT COUNT(*) AS Total
FROM shodanresults
WHERE country LIKE '%United States%'
GROUP BY org
ORDER BY COUNT(*) DESC;
