Dragon Insight

  1. Home
  2. Projects
  3. Dragon Insight
Full-Stack Web App

A peer-evaluation web app for Drexel team projects, where I designed the PostgreSQL database, RBAC model, and student dashboard.

Dragon Insight is a web app designed to facilitate the evaluation of student performance and feedback on team projects. It incorporates a teamwork rubric to assess how well students collaborate, enabling them to reflect at mid-term and end-of-term. Students fill out surveys evaluating themselves and their teammates and receive peer feedback reports, while professors access these evaluations for grading and for overall feedback on student collaboration and course performance.

My contributions

  • Designed and developed the Dragon Insight database in PostgreSQL.
  • Incorporated role-based access control within the database — for example, only professors can access the Grades table.
  • Created roles with the necessary privileges for each user type (Student, Professor, Admin).
  • Used JavaScript to build a student dashboard displaying evaluation scores over time as a line graph, alongside incomplete evaluations, due dates, and course information.
  • Developed a page for CSV import into the database so professors can load entire course rosters at once, and export data back out for grading.
